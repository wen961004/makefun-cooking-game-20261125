# Midnight Kitchen

A fully static, original cooking game built for the make.fun **Make the best cooking game** bounty.

Run locally:

```bash
node serve.ts
```

Build the make.fun output:

```bash
mkdir -p out
MAKEFUN_OUTPUT_DIR=out node main.ts
```
